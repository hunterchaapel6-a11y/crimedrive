CRIME DRIVE — BROWSER WEBSITE

Files:
- index.html       Landing page + embedded browser game
- CrimeDrive.html  The actual Crime Drive game

To publish:
1. Upload BOTH files to the same folder on your web host.
2. Make sure index.html is the default/home page.
3. Open the site's address in a browser.

The site is static and requires no server-side code or build step.
